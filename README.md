# loudandproud-social

Produktvideor för LoudandProuds sociala medier (TikTok, YouTube Shorts). Publiceras via GitHub Pages:
`https://bjorn-del.github.io/loudandproud-social/videos/<produkt>.mp4`

- `videos/` – färdiga videor, en per produkt (namn = Shopify-handle)
- `tools/make_video.py` – gör en 9:16-video av produktbilderna:
  `python3 tools/make_video.py ut.mp4 "Titel" "€pris" "store.loudandproud.se" bild1.jpg bild2.jpg ...`
